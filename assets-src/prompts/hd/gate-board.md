# Matching airport gate boards

Generated with the built-in imagegen tool on 2026-10-03, in response to the request to improve all three gate signs in PR #113. The existing approved twin flight board supplied the painted metal and ochre palette. Gate numbers and destinations remain live text from country config.

Use case: precise-object-edit. Asset type: reusable painted gate-sign housing for the same airport game. Input reference: the approved twin arrivals/departures board. Create ONE single gate sign, front-facing rectangle, width-to-height ratio about 2:1. Match the reference's charcoal metal casing, worn bevels, small warm brass corner screws, subtle hand-painted 1990s LucasArts texture and warm ochre yellow inset header. This is hardware only: absolutely NO TEXT, NO letters, NO numbers, no symbols. Broad blank yellow inset across the top, occupying about the top 25% of the interior, with an ample blank dark charcoal inset underneath for one large destination line. Remove the timetable column band and horizontal row dividers: this single sign is wayfinding, with one blank city field. Slim straight charcoal border at all four sides; tiny natural rounded outer corners. The casing must cover a rectangular old sign beneath it, so avoid large cutouts and keep opaque dark metal nearly to the rectangular edges. Preserve reference material quality, warm weathered metal, not glossy 3D. Very tight transparent margins outside the sign. No wall, windows, shop, cast shadow outside the silhouette, mounting poles, text, icons or presentation sheet. Truly transparent surrounding background. This is one sprite used three times with code-drawn gate numbers and destinations.

The full-quality source is `assets-src/approved/hall-gate-board.webp`. Run `npx tsx scripts/assets/gate-boards.ts` for the registered 39x24, 51x24 and 48x24 logical footprints, at both original and remaster densities. Original exports use hard alpha and the existing Hall palette.
